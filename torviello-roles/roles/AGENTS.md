# Agents: roles

- A role is a directory: `roles/<role-id>/`, with a `README.md` index and
  numbered `NN-<topic>.md` documents. The directory name is the stable role id
  that tickets use as `owner`.
- Keep each role definition outcome-focused: mission, duties, authority
  boundaries, records, and escalation.
- Do not grant approval authority to an agent or role here. Approval authority
  comes from approved requirements, decision records, and the governing controls.
- Keep documents numbered and self-contained; do not renumber an existing
  document to insert one. Add the next number instead.
- Update the role table in `README.md` when a role is added, renamed, or removed.
