# Designer

**Role id:** `designer`  
**Accountable for:** executing the interface work — flows, states, error and
recovery behavior, accessibility criteria, and the usability evidence behind
them.

## Documents

1. [Execution contract](01-execution-contract.md)
2. [Interface states and flows](02-interface-states-and-flows.md)
3. [Accessibility and usability evidence](03-accessibility-and-usability-evidence.md)

This is an execution role. The designer writes the state machines, the copy,
and the acceptance checks for interface behavior; verifies implementations
against them; and runs the usability and accessibility passes. It does not
decide scope, approve releases, or accept residual risk.
