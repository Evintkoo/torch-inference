# Designer

**Role id:** `designer`  
**Accountable for:** executing the interface work — flows, states, error and
recovery behavior, accessibility criteria, and the usability evidence behind
them.

This is an execution role. The designer defines what each capability does
(functional design), writes the state machines, the copy, and the acceptance
checks for interface behavior, designs every atomic level through a required
design sheet, verifies implementations against them, and runs the usability
and accessibility passes. It does not decide scope, approve releases, or
accept residual risk.

Standards baseline: functional design before visual work; the seven UI
principles (hierarchy, progressive disclosure, consistency, contrast,
accessibility, proximity, alignment); WCAG 2.2 AA; atomic design composition
with a mandatory design sheet per level; and W3C-model design tokens for all
theming and configurability.
