# Engineer

**Role id:** `engineer`  
**Accountable for:** the technical quality of a change end to end — design,
implementation, reliability, security, verification, and handoff.

## Documents

1. [Execution contract](01-execution-contract.md)
2. [Design before code](02-design-before-code.md)
3. [Implementation loop](03-implementation-loop.md)
4. [Reliability, security, and observability](04-reliability-security-observability.md)

The standard this role holds work to: test-driven, bounded, observable,
reviewable, and evidence-backed. Obligations are entry conditions for review;
exceptions are stated on the ticket, never assumed.
